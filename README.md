# Elder Care Homecare — Locations Map

A static page (`index.html`) listing all 12 Elder Care Homecare offices, grouped by state, each
with a live Google Maps embed and a "Get Directions" link.

Location names and addresses are sourced from Elder Care Homecare's verified Google Business
Profile listings. Map pins are geocoded live by Google from the address text at page load, not
from hardcoded coordinates.

To update a location, edit the `locations` array in `index.html`.
